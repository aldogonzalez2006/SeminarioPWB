# Práctica 02
## API Product
En esta práctica utilizando las annotations de Spring, implementamos una entidad Category y un método para devolver un Json con la lista de categorías existentes.
## Ejecucuión 
Verificar que este en la carpeta /product
Escribir en terminal: mvn spring-boot: run
Cuando compile y se complete la inicializacion, pegar en el buscador: http://localhost:8080/category
